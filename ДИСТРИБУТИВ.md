# Дистрибутив PlannerTaTe для Windows

**Готовый установщик: `dist/PlannerTaTe_Setup_1.2.exe`** (55 МБ) — один файл для нового компьютера:
мастер установки на русском, ярлыки, автозапуск, удаление через «Программы и компоненты».
Рядом лежит и просто `dist/PlannerTaTe.exe` (47,5 МБ) — переносной вариант без установки.
Внутри обоих уже всё: сервер, сам планировщик (сайт), приложение для телефона (APK), значок,
диалог выбора файла для карточек. Python на новом компьютере не нужен.

## Установщик (Inno Setup)
- Ставится **без прав администратора**, в папку пользователя: `%LOCALAPPDATA%\Programs\PlannerTaTe`
  (можно изменить в мастере), ярлыки — на рабочий стол и в меню «Пуск».
- **Галочка «Запускать при входе в Windows»** в шаге «Дополнительно» (по умолчанию включена).
  Если включена — создаётся ярлык в «Автозагрузке» с ключом `--quiet`: программа поднимается
  молча, без вкладки браузера, и напоминания работают сразу после включения компьютера.
  Галочку можно снять — тогда автозапуска не будет.
- Переключатель автозапуска есть и в самом приложении: правый щелчок по значку в трее →
  «Запускать при входе в Windows» (галочка).
- Удаление: через «Программы и компоненты». Если приложение работает, деинсталлятор так и скажет
  («закройте все экземпляры PlannerTaTe») — закройте его из трея («Выход») и повторите.
- Данные в `%APPDATA%\PlannerTaTe` при удалении НЕ трогаются (граф и ключ остаются на месте).
- Сборка установщика: `"C:\Users\Yar\AppData\Local\Programs\Inno Setup 6\ISCC.exe" PlannerTaTe.iss`


## Что происходит при первом запуске
1. Программа кладёт данные (граф, ключ доступа, состояние напоминаний) в `%APPDATA%\PlannerTaTe`
   — рядом с exe ничего не появляется, можно положить его на рабочий стол.
2. Создаёт ярлыки: на рабочем столе и в меню «Пуск» (по одному разу; существующие не трогает).
3. Поднимает сервер на порту 5001 и открывает страницу в браузере.
4. Ставит значок в трей: «Открыть PlannerTaTe», «Адрес и ключ для телефона», «Выход».
5. Журнал работы: `%APPDATA%\PlannerTaTe\plannertate.log`.

Первый запуск Windows спросит про доступ к сети — **разрешить для частных сетей**, иначе телефон
не подключится. SmartScreen может предупредить о «неизвестном издателе» (файл без подписи) —
«Подробнее» → «Выполнить в любом случае».

## Что внутри сборки (проверено живым запуском)
- главная страница 460 байт + `assets/index-*.js` 750 КБ + `assets/index-*.css` 52 КБ;
- `/apk` отдаёт приложение телефона 7,5 МБ — байт в байт как `app/PlannerTaTe.apk`;
- ключ доступа создаётся при первом запуске, `/ping`, `/api/phone/state`, `/api/ui_state` отвечают;
- значок в трее живёт, процесс завершается по «Выходу».

## Как обновить приложение для телефона, не пересобирая exe
Положить свежий файл как `app\PlannerTaTe.apk` рядом с `PlannerTaTe.exe` — он имеет приоритет над
тем, что зашит в сборку. Иначе пересобрать exe.

## Как пересобрать
```
cd C:/Users/Yar/PycharmProjects/PlannerTaTe
cd frontend && npm run build && cd ..
"C:/Users/Yar/AppData/Local/Programs/Python/Python312/python.exe" -m PyInstaller PlannerTaTe.spec --noconfirm --clean
"C:/Users/Yar/AppData/Local/Programs/Inno Setup 6/ISCC.exe" PlannerTaTe.iss
```
Установщик берёт готовый `dist/PlannerTaTe.exe`, поэтому порядок именно такой: сначала exe, потом Setup.
`--clean` (или удалить `build/PlannerTaTe`) обязателен: без этого PyInstaller может отдать прежний
файл из кэша, и внутрь не попадут свежие правки. Признак настоящей сборки — строки
`Building PYZ/PKG/EXE` в выводе.

## Состав исходников сборки
- `plannertate.py` — запуск: сервер в фоне, значок в трее, страница, ярлыки, журнал; режим
  `--pick-file` для диалога выбора файла (в собранном виде отдельного Python нет).
- `PlannerTaTe.spec` — что и откуда берётся (сайт, APK, иконка, скрытые модули tkinter/PyQt5).
- `PlannerTaTe_version.txt` — сведения о версии для свойств файла (1.1).
- `make_icon.py` — рисует `PlannerTaTe.ico` (плитка в фирменных цветах + мини-граф).
- `backend.py` — сам сервер; умеет работать и из исходников, и из сборки: `RES_DIR` (что читаем из
  сборки) и `BASE_DIR` (куда пишем данные). Переменные `PLANNERTATE_PORT`, `PLANNERTATE_DATA`, `PLANNERTATE_HOST`,
  `PLANNERTATE_NO_BROWSER`, `PLANNERTATE_NO_SHORTCUT` — для проверок, в обычной работе не нужны.

## Памятка для нового пользователя
`dist\ПАМЯТКА.pdf` — плотный лист 210×220 мм (печатается на A4, пустого низа нет): установка на
компьютер, установка приложения на телефон, как работает синхронизация, чего нельзя делать на
телефоне, что делать, если телефон не подключается. Исходник — `ПАМЯТКА.html` в корне проекта
(пересобрать PDF: headless Chrome с `--print-to-pdf`; имя файла держать латиницей).
Высота листа подобрана под содержимое: при 206–212 мм текст уходил на второй лист, 218 мм хватает.
Ширина ограничена 205 мм через `@media screen`, иначе картинка-предпросмотр растягивается в
широкую полосу. Памятку (включая имя установщика в ней — сейчас `PlannerTaTe_Setup_1.1.exe`)
обновляем ТОЛЬКО по отдельной команде Ярослава.

## Что не вошло (осознанно)
- MCP-сервер (`mcp/`) — он для ИИ-ассистентов, требует uv/Python, к дистрибутиву не относится.
- Подписанный сертификатом файл — SmartScreen предупреждает о «неизвестном издателе»; лечится только
  покупкой сертификата, для своих компьютеров не нужно.
- Правило брандмауэра, добавляемое установщиком автоматически — требует прав администратора, а
  установщик намеренно их не просит. Пользователь один раз отвечает «Разрешить» на запрос Windows.
